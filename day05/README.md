# Day 05

## 受講者が実装する場所

- `day05/app.py` の `answer_with_rag()`

## 目的

- 公開データを使ってRAGの最小構成を作る
- 回答に根拠（出典）を必ず付ける

## ゴール（完了条件）

- `Answer:` と `Sources:` が必ず出力される
- ヒットなしの場合でも `Sources:` に `- (none)` が出る

## データ出典/ライセンス

- データ名：自然公園法（第一条「目的」と第二条「定義」の短い抜粋）
- URL：[e-Gov法令検索：自然公園法](https://elaws.e-gov.go.jp/document?lawid=332AC0000000161_20250601_504AC0000000068)
- ライセンス：公共データ利用規約（第1.0版、PDL1.0）。利用時は出典を記載します。詳しくは[e-Gov利用規約](https://www.e-gov.go.jp/terms)を参照してください。

## 機能要件

コマンド

- `python -m day05.app` で起動できること（モジュール名は固定）

データ配置

- `day05/data/` 配下に、取り込むドキュメントを配置する
  - 形式はテキスト（`.txt`）でOK
  - 公開データから取得した本文を貼り付けてもよい

必須オプション

- `--question`：質問（文字列、必須）

出力（標準出力）

以下の形式で出力してください。

1. `Answer:` 行に回答
2. `Sources:` の下に参照元を列挙（最低1件）

例：

```
Answer: ...
Sources:
- <URL or ファイル名> (excerpt: "...")
```

検索ヒットなし時

- `Answer:` は「該当する根拠が見つからない」旨を返す
- `Sources:` は空にせず、代わりに `- (none)` を出す

終了コード

- 正常終了：`0`
- 入力不備：`2`
- 実行失敗（データ読み込み失敗等）：`1`

1. 公開データ（テキスト形式）を用意する
2. `day05/data/` ディレクトリを作成し、テキストファイルを配置する

```bash

# 例：公開データをテキストで保存
# ※ 出典とライセンスを上記「データ出典/ライセンス」セクションに記載すること
```

Windows（PowerShell）の場合：

```powershell

```

### 実行コマンド例

```bash

```

## リサーチメモ（任意）

調べたURLや、理解した要点をメモしてください。

- RAGの基本（分割、埋め込み、検索、プロンプトへの注入）
  - RAGは、事前に用意したデータを検索し、その結果をもとに回答を生成する仕組み。

    一般的なRAGの流れは以下の通り。

    ドキュメントを小さな単位に分割する
    分割したデータをベクトル化（埋め込み）する
    ユーザーの質問に関連するデータを検索する
    検索結果をプロンプトに含めてLLMへ渡す
    LLMが根拠をもとに回答を生成する

- 出典/ライセンスの確認方法
  - 公開データを使う前に、提供元のページで利用条件を確認し、利用条件に従って出典を記録する。
  - READMEには、利用したデータの出典URLとライセンス情報を記載する。

- 検索ヒットなし時の設計
  - 質問に合う文章が見つからないときは、推測で回答せず、根拠が見つからなかったことを表示する。
  - 出典欄には `- (none)` を表示し、質問の言い換えや資料の追加を案内する。
